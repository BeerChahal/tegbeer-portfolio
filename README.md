# Tegbeer Singh Portfolio

## Files
- `index.html` — portfolio structure/content
- `style.css` — design/responsive styling
- `script.js` — mobile navigation, scroll reveal, current year

## Run locally
Open `index.html` in your browser.

## Deploy on Vercel
1. Create a new GitHub repository.
2. Upload these 3 files to the repository.
3. In Vercel, choose **Add New Project** and import the GitHub repository.
4. Framework Preset: **Other** (or leave auto-detected).
5. Deploy.

## Before submitting
Check:
- GitHub link
- LinkedIn link
- Email
- Project information
- University name
- Add your CV download link when you have the final CV PDF.

## Included documents
The `certificates/` folder contains the uploaded certificate PDFs and `TegbeerCV.pdf` contains the uploaded CV. Certificate cards and the CV button use relative links so they continue to work after deployment.
